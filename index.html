DEMO

분류 데모

두 가지로 체험할 수 있습니다. ① 합성 테스트 이미지 12장 중 하나를 선택하면 우리가 학습한 모델이 실제로 계산한 결과가 나오고(불량 위치 표시와 확대 이미지도 함께 보여 줍니다), ② 내 이미지를 카메라로 찍거나 앨범·파일에서 골라 올리면 같은 모델이 분석하고, 불량 위치와 분석 과정을 단계별로 보여 줍니다. 정답을 알려 주면 내 데이터로 쌓입니다. 단, 합성 이미지로만 학습했기 때문에 실제 사진에서는 판정 보류가 나올 수 있습니다.

샘플을 선택하세요
이미지를 여기로 끌어놓아도 됩니다. 사진과 카메라 영상은 서버로 전송되지 않고 이 브라우저 안에서만 분석됩니다. 지원 범위는 웨이퍼 표면의 스크래치·오염입니다. 칩 모서리 깨짐(Chipping)이나 복잡한 회로 패턴은 "판정 보류"로 표시될 수 있습니다.
학습한 모델의 실제 출력 · 합성 테스트 이미지
CLASSES

불량 유형 설명

ScanWafer는 표면 이미지를 아래 3가지 클래스로 분류합니다.

정상 (Normal)

패턴이 고르고 눈에 띄는 선, 얼룩, 입자가 없는 표면입니다.

스크래치 (Scratch)

가늘고 긴 선형 흠집입니다. 이송이나 접촉 과정에서 생길 수 있습니다.

오염 (Contamination)

입자나 얼룩이 점 또는 덩어리 형태로 표면에 붙어 있는 상태입니다.

※ 위 3장의 웨이퍼 이미지는 우리가 설계한 생성기로 만든 합성 이미지입니다.

불량에 대해 더 알아보기

두 불량이 왜 생기고 어떤 모습인지 알면 이미지를 올렸을 때 무엇을 봐야 하는지 알 수 있습니다. 아래는 공개된 기술 자료를 정리한 내용입니다.

스크래치

가늘고 긴 선 모양의 흠집

  • 종류: 머리카락처럼 가는 선(위험도 중간), 넓고 깊은 홈(높음), 얕은 흠집이 모인 표면 마모(중간)로 나뉩니다.
  • 원인: 연마 공정에서 슬러리의 큰 입자(약 500nm 이상)가 패드와 웨이퍼 사이에 끼어 끌려가거나, 패드 조각이 떨어져 나와 긁는 경우가 대표적입니다. 장비 내부의 부스러기나 클린룸 입자도 원인이 됩니다.
  • 모양으로 알 수 있는 것: 사람이 웨이퍼를 다루다 생긴 흠집은 길거나 짧고 위치가 제각각이며 구불구불합니다. 장비가 만든 흠집은 직선이나 호 모양으로 같은 자리에 반복됩니다.
  • 우리 모델의 단서: 이상 픽셀이 한 줄로 이어지는 정도(직선 지지도), 가장 긴 선의 길이, 길쭉한 덩어리의 수.
오염

점이나 덩어리 형태로 붙은 이물질

  • 원인: 공기 중 먼지, 연마 부스러기, 화학 약품 잔류물, 작업자에 의한 오염, 포장 부스러기 등이 있습니다. 연마 뒤 세정이 부족하면 슬러리 입자가 남기도 합니다.
  • 모양: 작은 점이 흩어져 있거나 한곳에 뭉친 덩어리로 보입니다. 웨이퍼 맵 연구에서도 길게 늘어난 형태는 기계적 손상, 한곳에 몰린 덩어리는 식각 부족 같은 계통적 원인과 연결해서 구분합니다.
  • 주의할 점: 검사 장비 렌즈나 카메라 쪽의 먼지가 웨이퍼 불량으로 잘못 찍힐 수 있습니다. 같은 자리에서 반복해 찍어 확인해야 합니다.
  • 우리 모델의 단서: 가장 큰 군집의 크기, 군집 밀집도, 점·덩어리형 이상 영역의 수, 어두운 이상 영역의 비중.

참고: MCscope, Common Wafer Defects Detected Under Microscope · JEEZ, Silicon Wafer Surface Defects in CMP · Semiconductor Engineering, Detecting Slips, Scratches, Cracks In Wafers And Dies · OSTI, Automatic Classification of Spatial Signatures on Semiconductor Wafermaps

실제 검사 화면은 이렇게 보입니다

표면 검사 장비는 불량 위치를 박스로 표시하고 유형을 알려 줍니다. ScanWafer의 결함 위치 표시와 유형 분류가 맡으려는 역할이 바로 이 부분입니다.

이미지 출처
  1. 칩 표면 불량 유형 예시: Guangzhou Minder-Hightech Co., Ltd., "(AOI) 웨이퍼 2D 결함 검사" 제품 소개 페이지 · minder-semicon.com
  2. 웨이퍼 전체 검사 예시: ChatGPT(OpenAI)를 통해 얻은 이미지입니다. 원 출처는 확인하지 못했습니다.

이미지의 저작권은 각 원 소유자에게 있으며, 발표와 학습 목적의 참고용으로 인용했습니다. 별도의 사용 허가는 받지 않았습니다. 첫 번째 이미지의 Chipping(모서리 깨짐)은 현재 3클래스에 없으며, 클래스 확장 항목(로드맵 4단계)입니다.

로드맵 (계획)

STEP 1 · 지금

STEP 2

데이터와 모델

실제 장비 이미지(공개 데이터 또는 협의된 이미지)를 확보해 재학습하고, 정확도·클래스별 재현율·혼동행렬로 다시 평가합니다.

STEP 3

현장 검증

검사장비 엔지니어·품질 담당자 인터뷰로 문제 가설과 재검사 기준값(85%, 70%)을 확인하고 조정합니다.

STEP 4

연동과 확장

이미지 폴더·검사장비 연동, 결과 CSV의 API화, 클래스 추가와 조명·초점 조건 비교 기능으로 확장합니다. 사용자가 정답을 확인한 데이터를 서버에 쌓아 주기적으로 재학습하는 구조도 포함합니다.

※ 2~4단계는 아직 진행하지 않은 계획입니다. 우리 모델의 정확도는 합성 테스트 이미지 기준으로만 측정했고(데이터·모델 페이지), 실제 장비 이미지에서의 성능은 아직 모릅니다. 아래 수치는 외부 참고 사례입니다.

데이터셋 후보와 평가 계획

외부 자료 기준

WM-811K 웨이퍼 맵 (Kaggle 공개 데이터)

  • 웨이퍼 맵 811,457장 중 라벨이 있는 것은 172,950장, 실제 불량 패턴이 있는 것은 25,519장입니다.
  • 클래스는 Center, Donut, Edge-Loc, Edge-Ring, Loc, Random, Scratch, Near-full, none 9가지입니다.
  • 클래스 불균형이 큽니다. Edge-Ring 9,680장, Near-full 149장입니다.
  • 이미지 크기가 632종류라 입력을 맞추는 특징 추출이 필요합니다. (우리도 이미지를 200×200으로 맞춘 뒤 특징을 뽑습니다.)
  • 참고 사례(블로그 실습, 선형 SVM 59개 특징)의 테스트 정확도는 76.83%였고, Donut·Loc·Scratch의 오분류가 많았습니다. 우리 모델의 성능이 아닙니다.
가설 · 팀의 활용 계획

어떻게 참고할까요?

  • 평가 방법: 정확도만 보지 않고 클래스별 재현율과 혼동행렬로 평가합니다. 불균형 데이터에서는 정확도만으로 성능을 판단하기 어렵기 때문입니다.
  • 재검사 우선순위의 근거: 헷갈리는 클래스가 있다는 사례가 있으므로, 신뢰도가 낮은 이미지는 사람이 다시 보는 방식이 필요하다고 봅니다.
  • 확장 후보: 웨이퍼 단위 패턴 분류(Scratch, Edge-Ring 등)로 넓힐 때 후보 데이터로 검토합니다.
  • 한계: 웨이퍼 맵은 표면 사진과 형태가 달라서, 현재 3클래스 표면 이미지 분류의 학습 데이터로는 바로 쓸 수 없습니다.

※ 위 수치는 외부 블로그 실습 글에서 정리한 내용입니다. 데이터셋의 사용 조건은 Kaggle 페이지에서 직접 확인해야 합니다.

분류 체험에서 이미지를 올리고 정답을 알려 주면 그 정보가 데이터로 쌓입니다. 쌓인 데이터로 모델을 보정하면 내가 올린 이미지 유형에 더 잘 맞게 됩니다. 저장되는 것은 이미지가 아니라 숫자 특징 19개이고, 이 브라우저에만 저장되며 서버로 전송되지 않습니다.

최근에 알려 준 정답

※ 보정은 원래 모델에서 출발해, 내 데이터와 기존 학습 데이터 일부(150장)를 함께 복습하면서 가중치를 조금만 바꾸는 방식입니다. 기존 성능이 떨어지지 않았는지 합성 테스트 이미지 225장으로 바로 확인합니다. 여러 사람의 데이터를 합치려면 서버가 필요하며, 이 사이트에는 아직 없습니다. ("데이터가 쌓이면" 탭 참고)

DATASET

우리가 설계한 합성 데이터셋

표면 검사 이미지를 공개 데이터에서 구하지 못해서, 팀이 직접 이미지 생성기를 설계했습니다. 웨이퍼를 그리는 코드에 위치, 조명, 잡음, 불량의 크기와 농도를 무작위로 바꾸는 변수를 넣어서, 같은 클래스라도 이미지가 매번 다르게 나옵니다.

설계한 무작위 변수

왜 이렇게 만들었나요?

  • 공통: 웨이퍼 위치·크기, 다이 격자 간격과 선 농도, 밝기와 조명 방향, 센서 잡음, 흐린 얼룩. 모델이 격자나 얼룩을 불량으로 착각하지 않도록 일부러 넣었습니다.
  • 스크래치: 개수 1~3, 길이, 굵기, 대비, 휘어진 정도.
  • 오염: 입자 수 3~40, 크기, 군집 반경, 농도. 입자가 드문 어려운 경우도 포함됩니다.
  • 정상: 아주 작은 먼지처럼 불량이 아닌 흔적을 일부 넣었습니다.

직접 생성해 보기

버튼을 누를 때마다 생성기가 새 이미지를 만듭니다. (여기서는 웨이퍼 크기와 위치를 같게 맞춰서 보여 주고, 실제 학습용 데이터에서는 이 값도 무작위로 바뀝니다.)

※ 합성 이미지는 실제 장비 이미지와 다릅니다. 실제 데이터의 복잡함과 애매함은 반영하지 못했습니다. (실제 이미지 시험 결과는 "실제 이미지 시험" 탭 참고)

  • 처음 설계한 특징으로는 정확도가 약 60%였고, 격자선 제거와 직선·군집 특징을 추가해 개선했습니다. (이 과정에서 생성기 설정도 일부 조정해서 단순 비교는 어렵습니다.)

HOW IT CATCHES DEFECTS

외부 이미지가 들어오면 불량을 어떻게 잡나요?

어떤 이미지를 올려도 아래 순서로 처리합니다. 분류 체험에서 이미지를 올리면 단계별 화면과 불량 위치를 직접 볼 수 있습니다.

입력 정리

가운데를 정사각형으로 잘라 200×200 흑백으로 줄입니다. 이미지 크기가 제각각이어도 같은 입력으로 맞추기 위한 단계입니다.

배경 제거

각 점의 밝기에서 주변 평균 밝기를 빼서 조명 얼룩을 없애고, 주변과 다르게 튀는 부분만 남깁니다.

격자선 제거

가로·세로로 길게 이어지는 밝기 변화는 칩 사이의 격자선이므로 불량이 아닙니다. 행·열 방향의 반복 성분을 빼냅니다.

이상 영역 추출

배경 잡음의 5배보다 크게 튀는 점만 이상 영역으로 표시합니다. 이미지 가운데 원형 영역(약 4분의 3)만 봅니다.

덩어리 나누기

이어진 이상 점들을 덩어리로 묶고 가늘기와 크기를 계산합니다. 길쭉한 덩어리는 스크래치 후보, 둥글게 뭉친 덩어리는 오염 후보입니다. 이 덩어리가 이미지 위의 불량 위치 상자가 됩니다.

특징 19개 계산

덩어리 수, 가장 긴 선, 직선 지지도, 군집 크기, 어두운 이상 영역의 비중 등을 숫자로 정리합니다.

모델 판단

작은 신경망이 특징 19개로 정상·스크래치·오염의 확률을 계산합니다. 신뢰도가 기준보다 낮으면 사람이 다시 보도록 표시합니다.

판정 보류 (안전장치)

특징값이 학습 데이터 범위를 크게 벗어나면(표준편차의 7배 이상) 억지로 답하지 않고 "판정 보류"로 사람에게 넘깁니다.

잘 잡도록 올리는 방법
  • 웨이퍼가 이미지 가운데에 오도록 찍습니다. 가장자리 불량은 놓칠 수 있습니다.
  • 조명이 고르게 들어가도록 합니다. 동축 조명이 대비를 높이고 반사를 줄여 준다는 자료가 있습니다.
  • 한 이미지에 웨이퍼 하나, 가능하면 정사각형에 가깝게 자릅니다.
  • 옅은 스크래치는 조명 각도를 바꿔 한 번 더 찍으면 잘 보입니다.
잡지 못하는 경우
  • 모서리 깨짐(Chipping) 같은 3클래스 밖의 불량은 분류하지 못합니다.
  • 칩을 크게 확대한 이미지처럼 학습 데이터와 너무 다르면 판정 보류가 나옵니다.
  • 아주 옅은 스크래치는 놓칩니다. 합성 테스트에서 스크래치 재현율은 88%였습니다.
  • 합성 이미지로만 학습했으므로 실제 사진에서의 정확도는 아직 검증되지 않았습니다.

  • 중간에 20장에서 오히려 낮아지는 등 오르내림이 있습니다. 데이터가 적을 때는 어떤 이미지가 뽑혔는지에 따라 결과가 흔들립니다.
  • 350장에서도 곡선이 평평해지지 않았습니다.
가설 · 해석
  • 데이터를 더 모으면 정확도가 더 오를 가능성이 있습니다. 아직 350장보다 많은 데이터로는 확인하지 못했습니다.
  • 특히 스크래치처럼 놓치기 쉬운 불량의 다양한 사례를 모으는 것이 효과적일 것으로 봅니다.
  • 이 곡선은 합성 데이터의 결과이므로, 실제 이미지에서도 같은 추세인지는 확인이 필요합니다.

사용자가 올릴 때마다 정밀해지는 순환

구현1. 이미지 업로드분류 체험에서 이미지를 올립니다.

구현3. 정답 확인사용자가 맞는지 확인하거나 고칩니다. 신뢰도가 낮은 이미지는 우선 요청합니다.

구현5. 모델 보정내 데이터와 기존 데이터를 함께 복습해 가중치를 조금 바꿉니다.
구현6. 성능 확인합성 테스트 225장으로 기존 성능이 유지되는지 바로 확인합니다.

계획8. 검수와 재학습·배포잘못된 정답과 중복을 걸러내고 주기적으로 재학습해 새 모델을 배포합니다.
정직하게 말씀드리면
  • 지금 사이트는 서버가 없어서, 내가 쌓은 데이터는 내 브라우저 안에서만 모델을 바꿉니다. 다른 사람의 모델에는 영향을 주지 않습니다.
  • "여러 사람이 올릴수록 모두에게 정밀해지는" 단계는 7~8번이 구현되어야 가능하고, 로드맵에 넣어 두었습니다.
데이터를 모을 때의 원칙 (설계)
  • 이미지 대신 숫자 특징만 저장해서 검사 이미지 속 기밀이 새지 않도록 합니다.
  • 모델이 헷갈린 이미지부터 정답을 요청합니다. 같은 노력으로 더 많이 배울 수 있습니다.
  • 잘못된 정답 방지: 검수를 거치기 전에는 학습에 쓰지 않고, 보정 뒤에는 기존 테스트 성능을 반드시 확인합니다.

사실

  • 샘플 12장은 합성 테스트 이미지이고, 분류 결과와 신뢰도는 우리가 학습한 모델이 실제로 계산한 값입니다. 12장은 신뢰도 구간별로 골랐습니다.
  • 모델은 합성 이미지 1,500장으로만 학습했고, 합성 테스트 이미지 225장에서 정확도 95.1%를 기록했습니다. 실제 장비 이미지에서의 성능은 측정하지 못했습니다.
  • 실제 칩 확대 이미지 4장은 학습 범위를 벗어나 "판정 보류"가 되었습니다. (데이터·모델 > 실제 이미지 시험)
  • 분류 클래스는 정상, 스크래치, 오염 3가지입니다.
  • 이 페이지의 웨이퍼 이미지는 우리가 설계한 생성기로 만든 합성 이미지입니다.

가설

  • 수작업 확인에 시간이 많이 든다.
  • 판단 기준이 담당자마다 다를 수 있다.
  • 신뢰도 기반 재검사 우선순위가 도움이 된다.
  • 아이코어의 고객 지원이나 부가 소프트웨어로 쓸 수 있다.

확인 필요

  • 실제로 사용할 샘플 이미지와 데이터셋 (공개 WM-811K는 웨이퍼 맵 형식이라 표면 이미지와 다름)
  • 실제 장비 이미지에서의 정확도 (지금은 합성 이미지 기준 95.1%만 측정함)
  • 현장 담당자 인터뷰와 재검사 기준값
  • 참고 이미지: 웨이퍼 전체 검사 예시의 원 출처(ChatGPT를 통해 얻음), 그리고 두 이미지의 사용 허가
