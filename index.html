DEMO

분류 데모

두 가지로 체험할 수 있습니다. ① 합성 테스트 이미지 12장 중 하나를 선택하면 우리가 학습한 모델이 실제로 계산한 결과가 나오고(불량 위치 표시와 확대 이미지도 함께 보여 줍니다), ② 내 이미지를 올리면 같은 모델이 분석합니다. 단, 합성 이미지로만 학습했기 때문에 실제 사진에서는 판정 보류가 나올 수 있습니다.

샘플을 선택하세요
이미지를 여기로 끌어놓아도 됩니다. 사진은 서버로 전송되지 않고 이 브라우저 안에서만 분석됩니다. 지원 범위는 웨이퍼 표면의 스크래치·오염입니다. 칩 모서리 깨짐(Chipping)이나 복잡한 회로 패턴은 "판정 보류"로 표시될 수 있습니다.
학습한 모델의 실제 출력 · 합성 테스트 이미지
CLASSES

불량 유형 설명

ScanWafer는 표면 이미지를 아래 3가지 클래스로 분류합니다.

정상 (Normal)

패턴이 고르고 눈에 띄는 선, 얼룩, 입자가 없는 표면입니다.

스크래치 (Scratch)

가늘고 긴 선형 흠집입니다. 이송이나 접촉 과정에서 생길 수 있습니다.

오염 (Contamination)

입자나 얼룩이 점 또는 덩어리 형태로 표면에 붙어 있는 상태입니다.

※ 위 3장의 웨이퍼 이미지는 우리가 설계한 생성기로 만든 합성 이미지입니다. 실제 샘플로 교체 예정입니다.

실제 검사 화면은 이렇게 보입니다

표면 검사 장비는 불량 위치를 박스로 표시하고 유형을 알려 줍니다. ScanWafer의 결함 위치 표시와 유형 분류가 맡으려는 역할이 바로 이 부분입니다.

이미지 출처
  1. 칩 표면 불량 유형 예시: Guangzhou Minder-Hightech Co., Ltd., "(AOI) 웨이퍼 2D 결함 검사" 제품 소개 페이지 · minder-semicon.com
  2. 웨이퍼 전체 검사 예시: 원 출처를 찾지 못했습니다. (구글 이미지 검색에서 동일한 이미지가 나오지 않음)

이미지의 저작권은 각 원 소유자에게 있으며, 발표와 학습 목적의 참고용으로 인용했습니다. 별도의 사용 허가는 받지 않았습니다. 첫 번째 이미지의 Chipping(모서리 깨짐)은 현재 3클래스에 없으며, 클래스 확장 항목(로드맵 4단계)입니다.

STEP 1 · 지금

STEP 2

데이터와 모델

실제 장비 이미지(공개 데이터 또는 협의된 이미지)를 확보해 재학습하고, 정확도·클래스별 재현율·혼동행렬로 다시 평가합니다.

STEP 3

현장 검증

검사장비 엔지니어·품질 담당자 인터뷰로 문제 가설과 재검사 기준값(85%, 70%)을 확인하고 조정합니다.

STEP 4

연동과 확장

이미지 폴더·검사장비 연동, 결과 CSV의 API화, 클래스 추가와 조명·초점 조건 비교 기능으로 확장합니다.

※ 2~4단계는 아직 진행하지 않은 계획입니다. 우리 모델의 정확도는 합성 테스트 이미지 기준으로만 측정했고(데이터·모델 페이지), 실제 장비 이미지에서의 성능은 아직 모릅니다. 아래 수치는 외부 참고 사례입니다.

데이터셋 후보와 평가 계획

외부 자료 기준

WM-811K 웨이퍼 맵 (Kaggle 공개 데이터)

  • 웨이퍼 맵 811,457장 중 라벨이 있는 것은 172,950장, 실제 불량 패턴이 있는 것은 25,519장입니다.
  • 클래스는 Center, Donut, Edge-Loc, Edge-Ring, Loc, Random, Scratch, Near-full, none 9가지입니다.
  • 클래스 불균형이 큽니다. Edge-Ring 9,680장, Near-full 149장입니다.
  • 이미지 크기가 632종류라 입력을 맞추는 특징 추출이 필요합니다. (우리도 이미지를 200×200으로 맞춘 뒤 특징을 뽑습니다.)
  • 참고 사례(블로그 실습, 선형 SVM 59개 특징)의 테스트 정확도는 76.83%였고, Donut·Loc·Scratch의 오분류가 많았습니다. 우리 모델의 성능이 아닙니다.
가설 · 팀의 활용 계획

어떻게 참고할까요?

  • 평가 방법: 정확도만 보지 않고 클래스별 재현율과 혼동행렬로 평가합니다. 불균형 데이터에서는 정확도만으로 성능을 판단하기 어렵기 때문입니다.
  • 재검사 우선순위의 근거: 헷갈리는 클래스가 있다는 사례가 있으므로, 신뢰도가 낮은 이미지는 사람이 다시 보는 방식이 필요하다고 봅니다.
  • 확장 후보: 웨이퍼 단위 패턴 분류(Scratch, Edge-Ring 등)로 넓힐 때 후보 데이터로 검토합니다.
  • 한계: 웨이퍼 맵은 표면 사진과 형태가 달라서, 현재 3클래스 표면 이미지 분류의 학습 데이터로는 바로 쓸 수 없습니다.

※ 위 수치는 외부 블로그 실습 글에서 정리한 내용입니다. 데이터셋의 사용 조건은 Kaggle 페이지에서 직접 확인해야 합니다.

설계한 무작위 변수

왜 이렇게 만들었나요?

  • 공통: 웨이퍼 위치·크기, 다이 격자 간격과 선 농도, 밝기와 조명 방향, 센서 잡음, 흐린 얼룩. 모델이 격자나 얼룩을 불량으로 착각하지 않도록 일부러 넣었습니다.
  • 스크래치: 개수 1~3, 길이, 굵기, 대비, 휘어진 정도.
  • 오염: 입자 수 3~40, 크기, 군집 반경, 농도. 입자가 드문 어려운 경우도 포함됩니다.
  • 정상: 아주 작은 먼지처럼 불량이 아닌 흔적을 일부 넣었습니다.

학습 방법
  • 입력 특징 19개를 표준화한 뒤, 은닉층 14개의 신경망(tanh)으로 3클래스 확률을 계산합니다.
  • Adam 방식으로 학습하고, 검증 손실이 가장 낮은 시점의 가중치를 골랐습니다.
  • 초기값을 바꿔 5번 학습했을 때 테스트 정확도는 95.1~96.4%(평균 95.8%)였고, 검증 손실이 가장 낮은 모델(95.1%)을 사용합니다.
솔직한 해석
  • 스크래치 재현율이 88%로 가장 낮습니다. 스크래치 6장을 정상으로 판단했습니다.
  • 오분류 11장 중 2장은 신뢰도가 95%를 넘었습니다. 신뢰도가 높다고 반드시 맞는 것은 아닙니다.
  • 처음 설계한 특징으로는 정확도가 약 60%였고, 격자선 제거와 직선·군집 특징을 추가해 개선했습니다. (이 과정에서 생성기 설정도 일부 조정해서 단순 비교는 어렵습니다.)

※ 모든 수치는 우리가 만든 합성 테스트 이미지 기준입니다. 실제 장비 이미지에서의 성능이 아닙니다. 테스트 이미지는 학습과 시점 선택에 사용하지 않았습니다.

확인된 사실
  • 합성 웨이퍼로 학습한 모델은 칩을 확대한 실제 이미지에서는 학습 범위를 크게 벗어나, 4장 모두 판정 보류가 되었습니다.
  • 판정 보류 기준은 "특징값이 학습 데이터에서 표준편차의 7배 이상 벗어남"입니다. 합성 테스트 225장은 최대 5.9배였고, 위 칩 이미지는 10.1~22.0배였습니다.
  • 웨이퍼 전체 이미지는 범위 안이었고 정답(오염)을 맞혔습니다.
한계
  • 5장뿐이라 통계적 의미는 없습니다. 웨이퍼 1장을 맞힌 것은 우연일 수 있습니다.
  • 잘못된 답을 자신 있게 내놓는 대신 "모르겠다"고 말하게 만든 점이 이 시험의 핵심 결과입니다.
  • 다음 단계는 실제 장비 이미지로 재학습하고 검증하는 것입니다.
LIMITS

한계와 확인 필요 사항

사실, 가설, 확인 필요 항목을 구분해서 정리했습니다.

사실

  • 샘플 12장은 합성 테스트 이미지이고, 분류 결과와 신뢰도는 우리가 학습한 모델이 실제로 계산한 값입니다. 12장은 신뢰도 구간별로 골랐습니다.
  • 모델은 합성 이미지 1,500장으로만 학습했고, 합성 테스트 이미지 225장에서 정확도 95.1%를 기록했습니다. 실제 장비 이미지에서의 성능은 측정하지 못했습니다.
  • 실제 칩 확대 이미지 4장은 학습 범위를 벗어나 "판정 보류"가 되었습니다. (데이터·모델 > 실제 이미지 시험)
  • 분류 클래스는 정상, 스크래치, 오염 3가지입니다.
  • 이 페이지의 웨이퍼 이미지는 우리가 설계한 생성기로 만든 합성 이미지입니다.

가설

  • 수작업 확인에 시간이 많이 든다.
  • 판단 기준이 담당자마다 다를 수 있다.
  • 신뢰도 기반 재검사 우선순위가 도움이 된다.
  • 아이코어의 고객 지원이나 부가 소프트웨어로 쓸 수 있다.

확인 필요

  • 실제로 사용할 샘플 이미지와 데이터셋 (공개 WM-811K는 웨이퍼 맵 형식이라 표면 이미지와 다름)
  • 실제 장비 이미지에서의 정확도 (지금은 합성 이미지 기준 95.1%만 측정함)
  • 현장 담당자 인터뷰와 재검사 기준값
  • 참고 이미지: 웨이퍼 전체 검사 예시의 원 출처, 그리고 두 이미지의 사용 허가
