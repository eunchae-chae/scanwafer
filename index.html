누가 봐도 정상이거나 확실한 불량인 이미지까지 모두 사람이 하나씩 봐야 해서, 정말 정밀한 측정이 필요한 이미지에 쓸 시간이 줄어듭니다.

※ 위 내용은 팀이 정리한 문제 정의이며, 현장 조사가 아니라 아래 논문·문헌을 근거로 합니다.

논문·문헌 근거 (현장 조사는 하지 않았습니다)

이 문제는 논문이 먼저 말하고 있습니다

이번 프로젝트는 하루 만에 진행해서 현장 방문이나 인터뷰를 하지 않았습니다. 대신 문제 정의를 아래 문헌에서 확인한 내용에 근거해 정리했습니다. (표현은 팀이 요약한 것이고, 원문 링크를 달았습니다.)

  • 수작업 확인의 부담 (01): 숙련된 엔지니어는 웨이퍼 맵의 불량 패턴을 보고 원인을 찾을 수 있지만, 이것은 시간이 많이 걸리는 과정이라 컴퓨터 지원 도구가 필요하다고 설명합니다. 반도체 웨이퍼 표면 검사가 사람 전문가의 수작업 검토에 의존하며 느리고 부정확해지기 쉽다는 설명도 있습니다. — Wu·Jang·Chen, IEEE TSM 2015 (PDF) · Microelectronic Engineering 2005, "Defect detection on semiconductor wafer surfaces" (DOI)
  • 사람의 판단 편차와 피로 (02): 사람이 직접 검사하는 방식은 작업 시간이 많이 들고, 주관이나 피로가 정확도를 떨어뜨릴 수 있다고 정리됩니다. (SEM 이미지 검사 문헌 조사이며, 표면 이미지 전반의 일반적 설명으로 인용했습니다.) — "Automated Semiconductor Defect Inspection in Scanning Electron Microscope Images: a Systematic Review" (arXiv:2308.08376)
  • 자동화의 필요 (01): 웨이퍼 맵 패턴의 시각 검사는 지금도 사람이 수동으로 하는 경우가 많고, 이를 자동으로 분류해 인력과 시간을 줄이려는 연구가 이어지고 있습니다. — Sensors 2023, 23(4):1926 (MDPI)
  • 필터 방식의 근거 (03): 신뢰도가 낮을 때는 답하지 않고 넘기는 방식(reject option)으로 답한 것의 오류율을 낮출 수 있다는 연구가 있고, 우리 필터는 이 방법을 적용했습니다. (데이터·모델 > 신뢰도 향상) — Chow 1970, Geifman & El-Yaniv, NeurIPS 2017 (arXiv:1705.08500)

※ 위 문헌에서 "사람이 이미지 한 장을 확인하는 데 몇 초 걸린다" 같은 시간 수치는 확인하지 못했습니다. 그래서 기대 효과 계산기의 시간은 근거 없는 가정값으로 표시했습니다.

분류 데모

두 가지로 체험할 수 있습니다. 이미지는 한 장도, 수백~수천 장도 올릴 수 있습니다. 여러 장을 한꺼번에 올리면 이 페이지 아래의 대량 분류 구역에서 자동 분석으로 제외할 것과 사람이 정밀하게 볼 것을 나눠 줍니다. ① 합성 테스트 이미지 12장 중 하나를 선택하면 우리가 학습한 모델이 실제로 계산한 결과가 나오고(불량 위치 표시와 확대 이미지도 함께 보여 줍니다), ② 내 이미지를 카메라로 찍거나 앨범·파일에서 골라 올리면 같은 모델이 분석하고, 불량 위치와 분석 과정을 단계별로 보여 줍니다. 단, 합성 이미지로만 학습했기 때문에 실제 사진에서는 판정 보류가 나올 수 있습니다.

불량 유형 설명

ScanWafer는 표면 이미지를 아래 3가지 클래스로 분류합니다.

정상 (Normal)

패턴이 고르고 눈에 띄는 선, 얼룩, 입자가 없는 표면입니다.

스크래치 (Scratch)

가늘고 긴 선형 흠집입니다. 이송이나 접촉 과정에서 생길 수 있습니다.

오염 (Contamination)

입자나 얼룩이 점 또는 덩어리 형태로 표면에 붙어 있는 상태입니다.

※ 위 3장의 웨이퍼 이미지는 우리가 설계한 생성기로 만든 합성 이미지입니다.

불량에 대해 더 알아보기

두 불량이 왜 생기고 어떤 모습인지 알면 이미지를 올렸을 때 무엇을 봐야 하는지 알 수 있습니다. 아래는 공개된 기술 자료를 정리한 내용입니다.

스크래치

가늘고 긴 선 모양의 흠집

  • 종류: 머리카락처럼 가는 선(위험도 중간), 넓고 깊은 홈(높음), 얕은 흠집이 모인 표면 마모(중간)로 나뉩니다.
  • 원인: 연마 공정에서 슬러리의 큰 입자(약 500nm 이상)가 패드와 웨이퍼 사이에 끼어 끌려가거나, 패드 조각이 떨어져 나와 긁는 경우가 대표적입니다. 장비 내부의 부스러기나 클린룸 입자도 원인이 됩니다.
  • 모양으로 알 수 있는 것: 사람이 웨이퍼를 다루다 생긴 흠집은 길거나 짧고 위치가 제각각이며 구불구불합니다. 장비가 만든 흠집은 직선이나 호 모양으로 같은 자리에 반복됩니다.
  • 우리 모델의 단서: 이상 픽셀이 한 줄로 이어지는 정도(직선 지지도), 가장 긴 선의 길이, 길쭉한 덩어리의 수.
오염

점이나 덩어리 형태로 붙은 이물질

  • 원인: 공기 중 먼지, 연마 부스러기, 화학 약품 잔류물, 작업자에 의한 오염, 포장 부스러기 등이 있습니다. 연마 뒤 세정이 부족하면 슬러리 입자가 남기도 합니다.
  • 모양: 작은 점이 흩어져 있거나 한곳에 뭉친 덩어리로 보입니다. 웨이퍼 맵 연구에서도 길게 늘어난 형태는 기계적 손상, 한곳에 몰린 덩어리는 식각 부족 같은 계통적 원인과 연결해서 구분합니다.
  • 주의할 점: 검사 장비 렌즈나 카메라 쪽의 먼지가 웨이퍼 불량으로 잘못 찍힐 수 있습니다. 같은 자리에서 반복해 찍어 확인해야 합니다.
  • 우리 모델의 단서: 가장 큰 군집의 크기, 군집 밀집도, 점·덩어리형 이상 영역의 수, 어두운 이상 영역의 비중.

TRUST · PAPERS

신뢰도 향상: 논문의 방법을 적용해 직접 측정했습니다

"자동 분석으로 제외해도 되는가"는 기계가 말하는 신뢰도를 얼마나 믿을 수 있는가에 달려 있습니다. 그래서 불확실성·신뢰도 분야 논문의 방법 4가지를 우리 모델에 적용해 보고, 효과가 있었던 것과 없었던 것을 모두 숫자로 적었습니다. 이 페이지의 합성 테스트 수치는 지금 브라우저에서 계산한 값입니다.

적용 · 효과 있음

1. 확신 없으면 답하지 않기 (Reject option · Selective classification)

분류기가 신뢰도가 낮은 입력에는 답하지 않고 넘기면(coverage를 줄이면) 답한 것의 오류율을 낮출 수 있다는 방법입니다. Chow(1970)가 처음 제안했고, Geifman & El-Yaniv(2017)가 신경망에서 원하는 오류율에 맞춰 기준값을 고르는 방법을 보였습니다. ScanWafer의 "자동 분석 기준"이 바로 이 방법입니다. 기준은 검증 이미지에서 목표 정확도에 맞춰 고르고, 테스트 이미지로 확인했습니다.

적용해 보았으나 미채택

2. 신뢰도 보정 (Temperature scaling)

Guo 등(2017)은 현대 신경망의 신뢰도가 실제 정확도보다 높게 나오는 경향이 있고, 출력에 온도 T 하나를 나눠 주면 대부분 바로잡힌다고 보였습니다. 우리 모델에 적용해 T를 검증 이미지로 맞췄더니 효과가 없어서 쓰지 않았습니다. 이미 잘 맞는 모델(작은 신경망)이기 때문입니다. 아래 표에 결과가 있습니다.

적용 · 효과 있음

3. 기존 지식 복습 + 원래 가중치 유지 (Experience replay · L2-SP)

새 데이터로 추가 학습하면 기존 성능을 잊을 수 있습니다(catastrophic forgetting). Rolnick 등(2019)의 경험 재생(옛 데이터를 섞어 복습)과 Li 등(2018)의 L2-SP(원래 가중치에서 멀어지지 않게 규제)를 함께 썼습니다. 학습용 이미지 150장을 복습용으로 항상 섞고, 새 데이터에는 개수에 따른 가중치를 줍니다. 아래 "학습 향상도" 결과가 이 방법으로 얻은 것입니다.

적용해 보았으나 이점 없음

4. 헷갈리는 것부터 학습 (Active learning · Uncertainty sampling)

사람이 정답을 달 이미지를 모델이 가장 헷갈리는 것부터 고르면 같은 노력으로 더 빨리 배운다는 방법입니다(Settles, 2009 정리). 우리 실험에서는 무작위로 고른 것보다 일관되게 좋지 않았습니다. 그래서 "더 낫다"고 주장하지 않고, 분류 체험 화면에서 두 방식을 나란히 보여 줍니다.

  • 학습 데이터가 충분해지면 자동 분석에 섞이는 오분류가 크게 줄었습니다(21장 → 2장). 필터를 믿을 수 있는 정도가 올라간 것입니다.
  • 신뢰도가 실제 정확도와 어긋나는 정도(ECE)도 13.1%에서 4.9%로 줄었습니다.
  • 그 대신 모델이 더 신중해져서 자동 분석 비율은 62%에서 39%로 줄었습니다. 신뢰도를 얻는 만큼 사람이 볼 이미지가 늘어납니다.
  • 전체 정확도는 78.0%에서 79.7%로 소폭만 올랐습니다. 학습의 주된 효과는 "정확도"보다 "자동 분석을 믿을 수 있게 되는 것"입니다.
솔직한 한계
  • 학습 데이터가 적을 때(25~49장)는 오히려 나빠졌습니다. 오분류가 21장에서 30장으로 늘었습니다. 적은 데이터로 보정하면 모델이 과신합니다.
  • 새로운 종류의 이미지에서는 신뢰도가 과신됩니다. 합성 테스트에서는 자동 분석 정확도가 98.8%였지만, 더 어려운 샘플에서는 90.0%였습니다. 학습 범위를 벗어난 이미지일수록 "판정 보류"와 기준 점검이 중요합니다.
  • 평가용 300장, 나눔 1번의 결과라서 오차가 있습니다. 모든 데이터가 합성 이미지이고, 실제 장비 이미지에서의 효과는 확인하지 못했습니다.
  • 사람이 정답을 달아야 학습이 됩니다. 그래서 필터가 남긴 이미지(사람이 어차피 정밀하게 보는 것)의 결과를 학습에 다시 쓰는 순환을 만들었습니다.

1. 논문이 한 일 (원문 확인)

데이터
  • 실제 반도체 공장에서 46,293개 로트(lot)의 웨이퍼 맵 811,457장을 모아 공개했습니다. 연구는 TSMC의 지원을 받았습니다.
  • 전체의 약 20%에 분야 전문가가 9가지 유형(Center, Donut, Edge-local, Edge-ring, Local, Near-full, Random, Scratch, 패턴 없음)을 직접 라벨로 붙였습니다. 학습용 54,356장, 테스트용 118,595장입니다.
  • 논문은 이 데이터를 "당시 일반에 공개된 가장 큰 웨이퍼 맵 데이터"라고 설명합니다.
방법과 결과
  • 핵심 아이디어: 웨이퍼 맵 원본을 그대로 쓰지 않고, 회전·크기에 영향을 덜 받는 특징으로 줄여서 분류합니다. 대량 데이터를 빠르게 처리하기 위해서입니다.
  • 특징: Radon 변환 기반 40개 + 기하 기반 18개를, 노이즈 제거 전·후로 각각 뽑아 합친 116개.
  • 분류기: 2단계 SVM. 1단계는 "불량 패턴이 있는가", 2단계는 "8가지 중 무엇인가". 샘플이 적은 유형에는 더 큰 비용을 줍니다.
  • 결과: 테스트 118,595장에서 정확도 94.63%. 원본 맵을 쓴 딥러닝과 이미지 모멘트 방식보다 높았고, 웨이퍼 1장 분석에 약 0.07초가 걸렸습니다. 가장 자주 헷갈린 것은 Local이었습니다.
기하·통계 특징 (논문 III절)
  • 가장 두드러진 영역(면적 또는 둘레가 최대인 불량 덩어리)의 면적비, 둘레비, 웨이퍼 중심과의 최대·최소 거리, 장축·단축 비율, solidity, 이심률(eccentricity).
  • 불량 칸 비율: 웨이퍼 전체, 그리고 가장 바깥 두 고리. 가장자리에 생기는 Edge-ring·Edge-local을 구분하기 위해서입니다.
  • 선형 특징: Hough 변환으로 찾은 직선 개수 (Scratch용).
라벨 관리와 신뢰도 (논문 IV절, II절)
  • 경계에 있는 샘플을 전문가가 다시 확인합니다. SVM은 경계 근처의 서포트 벡터로 결정되고 이들이 잘못 라벨됐을 가능성이 높아서, 웹 화면으로 전문가가 재검토·재라벨한 뒤 다시 학습시킵니다.
  • 분류 신뢰도가 일정 기준보다 낮으면 새로운 불량 패턴으로 따로 만들어 다루도록 확장할 수 있다고 설명합니다.
  • 1단계에서 패턴 유무의 오탐·미탐 균형을 비용 값으로 조절합니다.

각 점의 밝기에서 주변 평균 밝기를 빼서 조명 얼룩을 없애고, 주변과 다르게 튀는 부분만 남깁니다.

격자선 제거

가로·세로로 길게 이어지는 밝기 변화는 칩 사이의 격자선이므로 불량이 아닙니다. 행·열 방향의 반복 성분을 빼냅니다.

이상 영역 추출

배경 잡음의 5배보다 크게 튀는 점만 이상 영역으로 표시합니다. 이미지 가운데 원형 영역(약 4분의 3)만 봅니다.

덩어리 나누기

이어진 이상 점들을 덩어리로 묶고 가늘기와 크기를 계산합니다. 길쭉한 덩어리는 스크래치 후보, 둥글게 뭉친 덩어리는 오염 후보입니다. 이 덩어리가 이미지 위의 불량 위치 상자가 됩니다.

특징 19개 계산

덩어리 수, 가장 긴 선, 직선 지지도, 군집 크기, 어두운 이상 영역의 비중 등을 숫자로 정리합니다.

모델 판단

작은 신경망이 특징 19개로 정상·스크래치·오염의 확률을 계산합니다. 신뢰도가 기준 이상이면 자동 분석 완료로 제외하고, 기준보다 낮으면 사람이 정밀하게 볼 이미지로 남깁니다.

판정 보류 (안전장치)

특징값이 학습 데이터 범위를 크게 벗어나면(표준편차의 7배 이상) 억지로 답하지 않고 "판정 보류"로 사람에게 넘깁니다.

잘 잡도록 올리는 방법
  • 웨이퍼가 이미지 가운데에 오도록 찍습니다. 가장자리 불량은 놓칠 수 있습니다.
  • 조명이 고르게 들어가도록 합니다. 동축 조명이 대비를 높이고 반사를 줄여 준다는 자료가 있습니다.
  • 한 이미지에 웨이퍼 하나, 가능하면 정사각형에 가깝게 자릅니다.
  • 옅은 스크래치는 조명 각도를 바꿔 한 번 더 찍으면 잘 보입니다.
잡지 못하는 경우
  • 모서리 깨짐(Chipping) 같은 3클래스 밖의 불량은 분류하지 못합니다.
  • 칩을 크게 확대한 이미지처럼 학습 데이터와 너무 다르면 판정 보류가 나옵니다.
  • 아주 옅은 스크래치는 놓칩니다. 합성 테스트에서 스크래치 재현율은 88%였습니다.
  • 합성 이미지로만 학습했으므로 실제 사진에서의 정확도는 아직 검증되지 않았습니다.
LIMITS

한계와 확인 필요 사항

사실, 가설, 확인 필요 항목을 구분해서 정리했습니다.

사실

  • 샘플 12장은 합성 테스트 이미지이고, 분류 결과와 신뢰도는 우리가 학습한 모델이 실제로 계산한 값입니다. 12장은 신뢰도 구간별로 골랐습니다.
  • 웨이퍼 맵 분류 모델은 실제 공장 데이터 WM-811K(5,604장 추출)로 학습했고, 테스트 맵 840장에서 정확도 84.2%를 기록했습니다.
  • 사진(표면 이미지) 분석 모델은 WM-811K에 사진이 없어서 팀이 생성한 합성 이미지(전체 1,500장 중 학습용 1,050장)로만 학습했고, 따로 둔 합성 테스트 이미지 225장에서 정확도 95.1%를 기록했습니다. 실제 장비 이미지에서의 성능은 측정하지 못했습니다.
  • 실제 칩 확대 이미지 4장은 학습 범위를 벗어나 "판정 보류"가 되었습니다.
  • 분류 클래스는 정상, 스크래치, 오염 3가지입니다.
  • 자동 분석의 신뢰도는 모델이 학습한 범위 안에서만 믿을 수 있습니다. 더 어려운 별도 합성 샘플 1,000장에서는 자동 분석 정확도가 합성 테스트(98.8%)보다 낮은 약 90%였습니다. (데이터·모델 > 신뢰도 향상)
  • 이 페이지의 웨이퍼 이미지는 우리가 설계한 생성기로 만든 합성 이미지입니다.

가설

  • 수작업 확인에 시간이 많이 든다. (문헌 근거: 문제 정의 페이지, 시간 수치는 확인하지 못함)
  • 판단 기준이 담당자마다 다를 수 있다. (문헌 근거: 문제 정의 페이지)
  • 자동 분석 필터가 사람이 정밀하게 측정할 이미지 수를 줄여 준다.
  • 아이코어의 고객 지원이나 부가 소프트웨어로 쓸 수 있다.

확인 필요

  • 실제로 사용할 샘플 이미지와 데이터셋 (공개 WM-811K는 웨이퍼 맵 형식이라 표면 이미지와 다름)
  • 실제 장비 이미지에서의 정확도 (지금은 합성 이미지 기준 95.1%만 측정함)
  • 현장 검증(이번 프로젝트는 하루 만에 진행해 현장 조사 없이 논문·문헌 근거로 정리했음)과 자동 분석을 허용할 기준값(신뢰도 %, 목표 정확도)
  • 참고 이미지: 웨이퍼 전체 검사 예시의 원 출처(ChatGPT를 통해 얻음), 그리고 두 이미지의 사용 허가
