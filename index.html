문제 정의

DEMO

분류 데모

두 가지로 체험할 수 있습니다. ① 샘플 12장 중 하나를 선택하면 미리 정해 둔 가상 결과가 나오고("결함 위치 표시"로 불량 의심 영역도 볼 수 있습니다), ② 내 이미지를 올리면 이미지 픽셀을 실제로 분석한 프로토타입 결과가 나옵니다.

샘플을 선택하세요
이미지를 여기로 끌어놓아도 됩니다. 사진은 서버로 전송되지 않고 이 브라우저 안에서만 분석됩니다. 지원 범위는 웨이퍼 표면의 스크래치·오염입니다. 칩 모서리 깨짐(Chipping)이나 복잡한 회로 패턴은 "판정 보류"로 표시될 수 있습니다.
목업 데모 · 실제 모델 추론이 아닙니다
CLASSES

불량 유형 설명

ScanWafer는 표면 이미지를 아래 3가지 클래스로 분류합니다.

정상 (Normal)

패턴이 고르고 눈에 띄는 선, 얼룩, 입자가 없는 표면입니다.

스크래치 (Scratch)

가늘고 긴 선형 흠집입니다. 이송이나 접촉 과정에서 생길 수 있습니다.

오염 (Contamination)

입자나 얼룩이 점 또는 덩어리 형태로 표면에 붙어 있는 상태입니다.

※ 위 3장의 웨이퍼 이미지는 설명용으로 코드로 그린 임시 이미지입니다. 실제 샘플로 교체 예정입니다.

실제 검사 화면은 이렇게 보입니다

표면 검사 장비는 불량 위치를 박스로 표시하고 유형을 알려 줍니다. ScanWafer의 결함 위치 표시와 유형 분류가 맡으려는 역할이 바로 이 부분입니다.

※ 위 2장은 팀이 제공한 참고 자료입니다. 출처와 사용 허가는 확인이 필요합니다. 첫 번째 이미지의 Chipping(모서리 깨짐)은 현재 3클래스에 없으며, 클래스 확장 항목(로드맵 4단계)입니다.

BATCH

배치 결과 요약 + CSV

여러 장을 한 번에 분류했다고 가정한 결과 요약입니다. 결과는 CSV로 내려받을 수 있습니다.

※ 표의 결과는 데모용 가상 데이터입니다.

RE-INSPECTION

재검사 우선순위

신뢰도가 낮은 이미지부터 사람이 다시 확인하도록 정렬합니다. 슬라이더로 기준을 바꿔 보세요. 표, 요약, 아래 기대 효과 계산이 바로 바뀝니다.

85%

※ 기준값은 임의로 정한 예시이며, 실제 기준은 현장 의견을 받아 정해야 합니다. (기본값 85%, 우선 확인 70%)

로드맵 (계획)

STEP 1 · 지금

구상과 프로토타입

3클래스 분류 화면, 신뢰도 표시, 배치 요약·CSV, 재검사 우선순위 설계. 업로드 이미지는 규칙 기반으로 분석합니다.

STEP 2

데이터와 모델

사용 가능한 공개 데이터셋 또는 협의된 이미지를 확보해 학습하고, 정확도·클래스별 재현율·혼동행렬로 평가합니다.

STEP 3

현장 검증

검사장비 엔지니어·품질 담당자 인터뷰로 문제 가설과 재검사 기준값(85%, 70%)을 확인하고 조정합니다.

STEP 4

연동과 확장

이미지 폴더·검사장비 연동, 결과 CSV의 API화, 클래스 추가와 조명·초점 조건 비교 기능으로 확장합니다.

※ 2~4단계는 아직 진행하지 않은 계획입니다. 우리 모델의 정확도는 측정 전이어서 성능 수치를 싣지 않았습니다. 아래의 수치는 외부 참고 사례입니다.

데이터셋 후보와 평가 계획

외부 자료 기준

WM-811K 웨이퍼 맵 (Kaggle 공개 데이터)

  • 웨이퍼 맵 811,457장 중 라벨이 있는 것은 172,950장, 실제 불량 패턴이 있는 것은 25,519장입니다.
  • 클래스는 Center, Donut, Edge-Loc, Edge-Ring, Loc, Random, Scratch, Near-full, none 9가지입니다.
  • 클래스 불균형이 큽니다. Edge-Ring 9,680장, Near-full 149장입니다.
  • 이미지 크기가 632종류라 입력을 맞추는 특징 추출이 필요합니다.
  • 참고 사례(블로그 실습, 선형 SVM 59개 특징)의 테스트 정확도는 76.83%였고, Donut·Loc·Scratch의 오분류가 많았습니다. 우리 모델의 성능이 아닙니다.
가설 · 팀의 활용 계획

어떻게 참고할까요?

  • 평가 방법: 정확도만 보지 않고 클래스별 재현율과 혼동행렬로 평가합니다. 불균형 데이터에서는 정확도만으로 성능을 판단하기 어렵기 때문입니다.
  • 재검사 우선순위의 근거: 헷갈리는 클래스가 있다는 사례가 있으므로, 신뢰도가 낮은 이미지는 사람이 다시 보는 방식이 필요하다고 봅니다.
  • 확장 후보: 웨이퍼 단위 패턴 분류(Scratch, Edge-Ring 등)로 넓힐 때 후보 데이터로 검토합니다.
  • 한계: 웨이퍼 맵은 표면 사진과 형태가 달라서, 현재 3클래스 표면 이미지 분류의 학습 데이터로는 바로 쓸 수 없습니다.

※ 위 수치는 외부 블로그 실습 글에서 정리한 내용입니다. 데이터셋의 사용 조건은 Kaggle 페이지에서 직접 확인해야 합니다.

LIMITS

한계와 확인 필요 사항

사실, 가설, 확인 필요 항목을 구분해서 정리했습니다.

사실

  • 샘플 12장의 분류 결과와 신뢰도는 모두 가상 값(목업)입니다.
  • 업로드 이미지 분석은 학습된 AI 모델이 아니라 규칙 기반 프로토타입입니다. (중앙 원형 영역에서 어둡거나 밝은 이상 영역을 찾아 선형/덩어리로 구분, 수평·수직 격자선은 제외). 코드로 그린 가상 이미지 90장 자체 시험에서는 86장이 맞았지만, 같은 코드로 만든 이미지라 실제 웨이퍼 성능을 뜻하지는 않습니다.
  • 분류 클래스는 정상, 스크래치, 오염 3가지입니다.
  • 이 페이지의 이미지는 코드로 그린 임시 이미지입니다.

가설

  • 수작업 확인에 시간이 많이 든다.
  • 판단 기준이 담당자마다 다를 수 있다.
  • 신뢰도 기반 재검사 우선순위가 도움이 된다.
  • 아이코어의 고객 지원이나 부가 소프트웨어로 쓸 수 있다.

확인 필요

  • 실제로 사용할 샘플 이미지와 데이터셋 (공개 WM-811K는 웨이퍼 맵 형식이라 표면 이미지와 다름)
  • 실제 모델의 정확도 (업로드 분석기는 실제 웨이퍼 사진으로 검증되지 않음)
  • 현장 담당자 인터뷰와 재검사 기준값
  • 참고 이미지(칩·웨이퍼 검사 예시)의 출처와 사용 허가
